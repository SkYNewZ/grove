# Grove

A native macOS app that lists the git worktrees of all your repositories, shows which ones are safe to delete, and opens them in a terminal, Claude Code or their pull request in one click.

## Features

- **Every worktree, every repo**: scans the folders you choose and lists all worktrees, with their status and size on disk.
- **Safe cleanup**: flags the worktrees you can remove and deletes them without losing work (backup ref, Trash, locked, unmerged and unique detached states refused).
- **One-click launch**: open a worktree in your terminal, resume a Claude Code session, or jump to its GitHub PR / GitLab MR.
- **Menu bar and explain**: a menu bar view of your repos, plus a short summary of what a worktree was about, written by Claude.

Requires macOS 26. The interface is in French.
